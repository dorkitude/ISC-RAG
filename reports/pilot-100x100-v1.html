A 100-document MediaSum test-split run compared fixed, turn-aware, semantic, and fact retrieval using the same Fireworks Nomic embedding model and 10,000 source-anchored probes. The fact result below is the higher-coverage rerun.

This is a plumbing / lexical-stress pilot, not a paper result. Every probe is deterministically anchored to a phrase in a source turn. That makes the test reproducible and useful for storage/retrieval debugging, but not representative of natural information needs. The higher-coverage fact run uses 2.5k-byte inputs and at most five facts per input; it is still not a frozen paper fact configuration.

Readout

Increasing coverage from 629 to 2,353 facts raised fact recall by 3.82 points (11.69% → 15.51%; a 32.7% relative increase). That confirms coverage matters, but facts still trail chunks because this lexical test rewards original wording and the extractor can still miss or rephrase relevant claims. The next useful experiment is an evidence-bundle fact representation evaluated on independently authored natural questions.

Question namespace: pilot-100x100-v1. Fact run: pilot-coverage-v2. All conditions use the same 100 MediaSum test documents, Fireworks nomic-ai/nomic-embed-text-v1.5, cosine pgvector retrieval, and top-k = 5.
