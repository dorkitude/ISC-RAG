# Source Claim Ledger — Fact Study 2

**Corpus:** MediaSum validation split
**Documents:** `NPR-1781`, `NPR-2291`, `NPR-967`
**Purpose:** A source-only audit ledger for development-study coverage and
fidelity checks. It is deliberately not a question set and does not use
MediaSum summaries. Turn numbers are zero-based `turns.ordinal` values in the
local ISC-RAG PostgreSQL corpus. Each evidence quotation is a short, exact,
contiguous excerpt from that turn.

The ledger records explicit atomic claims, including the source's attribution
and qualifications. It does not treat a host's question as an asserted fact
unless a speaker explicitly endorses it.
